# Kana – Japanisch lernen

Gebaute Version einer persönlichen Lern-App (PWA): Hiragana, Katakana, Wörter, Kanji und Grammatik mit
Spaced Repetition. Nicht kommerziell. Der Quellcode liegt lokal.
